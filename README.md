# 🛠️ ProGear

A clean and responsive web project built with **HTML**, **CSS**, and **JavaScript** showcasing the **ProGear** product line. The site features a user-friendly interface and modern design to highlight product details effectively.

---

## 🌐 Live Demo

🔗 [Check out the live demo here](https://ardann21.github.io/ProGear/)

## 🧩 Features

- Fully responsive layout with CSS
- Interactive elements powered by vanilla JavaScript
- Modern and clean design focusing on usability
- Lightweight and fast loading

---

## 🛠️ Tech Stack

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
